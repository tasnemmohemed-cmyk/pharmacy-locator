# Pharmacy Locator

A Python-based application designed to manage and display pharmacy data, including location details, available medications, crowd status, and professional profiles of on-duty pharmacists.

## Features
- Manages pharmacy and medication data efficiently.
- Displays details about on-duty pharmacists and their qualifications.
- Tracks real-time status and availability of products.

## Tech Stack
- **Language:** Python
